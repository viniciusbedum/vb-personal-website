# Security policy

## Supported versions

Only the latest release (and `main`) gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead: go to the **Security** tab of this repository and click **Report a vulnerability**. Include what you found, where, and how to reproduce it.

You'll get an answer as soon as possible, and a fix is released before the details are made public.
